# 陈默 · 工作简历

一个轻量级的工作简历管理工具，支持网页浏览、在线编辑、本地保存，以及导出 Word / JSON 文件。

## 功能

- **浏览**：以清晰排版展示完整简历
- **编辑**：在线修改基本信息、工作经历、项目经历、教育背景、专业技能
- **保存**：数据自动存储在浏览器 localStorage
- **导出 Word**：一键生成 `.docx` 文件，方便投递
- **导入/导出 JSON**：备份或迁移简历数据

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

启动后访问终端显示的本地地址（通常是 `http://localhost:5173`）。

## 使用说明

1. 打开页面后，点击 **编辑** 标签，将示例数据替换为你的真实信息
2. 点击 **保存**，数据会写入浏览器本地存储
3. 切换到 **浏览** 标签预览效果
4. 点击 **导出 Word** 下载 `.docx` 文件

## 数据文件

默认示例数据位于 `src/data/resume.json`。你也可以通过 **导出 JSON** 备份数据，或通过 **导入 JSON** 恢复。

## 技术栈

- React + TypeScript + Vite
- Tailwind CSS
- docx + file-saver（Word 导出）
